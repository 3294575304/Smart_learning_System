# 错题来源与课程归属

错题课程来自冻结作答的来源：正式作业所属班级课程，或课程推荐周期courseCycle。通用推荐没有courseCycle，旧版班级也可能未绑定课程，这类记录保留在LEGACY兼容查询中，学生界面命名为“通用与历史错题”，放在其他来源分组。

该分组不是一门课程，也不表示数据损坏。只要存在本人原始作答、题目与已有反馈，就不因为缺少课程周期而删除；不按题库当前绑定强行重写历史归属。无可见记录时不生成此筛选选项，默认不自动选中LEGACY。

错题、收藏和掌握状态分别保存；取消收藏不删除错题。复习页签使用原生链接完整导航，保留可用课程、章节及返回提示，避免客户端流式切换挂起；通用／历史分类不作为收藏的新课程参数。
