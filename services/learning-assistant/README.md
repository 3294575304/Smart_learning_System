# AI 课程学习助手

## 本次核对的原有实现

原有“AI 对话式自我反思”只将自述转换为 summary、goals、difficulties、learningHabits 和 practiceRequest，支持草稿、修改、确认、删除及旧练习发起入口。它不是课程答疑服务：没有问题解答、多轮上下文、章节选择或依据客观画像的掌握总结。

## 新流程

1. 学生在练习中心选择已加入的课程，以及正式图谱中的知识点或章节。
2. 提问后显示 AI 解释、平台根据历史已评分作答整理的掌握情况，以及本次交流反映的待验证学习线索。
3. 首次答疑不生成建议或练习。学生点击“需要学习建议”后，AI 给出相关建议和练习／测试入口。
4. 入口携带 courseId、conceptId 或 chapterId，以及 PRACTICE／TEST 模式。练习中心显示条件，学生再次点击生成后才从题库组题。
5. 可将交流整理为自我反思，学生先编辑并主动保存为待确认草稿，再在下方记录确认、修改或删除。自述不覆盖客观掌握度。

新入口为 `POST /api/student/courses/:courseId/learning-assistant`。请求含 topic、text、phase 和最多六条历史消息，客户端不能提供用户身份、角色、画像、练习 URL 或模型参数。角色、成员关系、正式图谱版本、主题所属课程均由服务端校验。新问答自动保存；单段最多 40 轮，模型只使用最近六条消息。切换主题开始新段对话；旧记录仍可恢复。

## 数据与版本

- 新增 StudentLearningConversation 和增量 migration，仅保存当前学生的课程问答、主题、时间、提示词/模型版本及当时的客观摘要；旧临时对话未曾保存，无法补回。AITutoringRecord 是绑定具体题目的旧辅导记录，不适合承载知识点/章节会话，因此保持兼容并单独增加课程会话模型。
- 显式保存的自述继续复用 StudentSelfReflection，不影响旧记录；客观掌握度继续使用已有画像／掌握度服务。
- 客观摘要使用“熟练掌握、基本掌握、需要巩固、暂未评估”，不把一次提问当作评分。
- 回包记录图谱版本、画像修订、Provider、模型、提示词版本 `course-learning-assistant-v1` 及降级标记；完整会话的持久化追溯不在本次范围内。
- 不改变现有题库候选、权限和确定性组题规则。继承当前开发目录的练习规则，包括其已实施的章节／知识点范围与固定模板调整。

## AI、隐私与安全边界

- 通过统一 AIProvider 的可选 `answerCourseLearningQuestion` 方法调用 OpenAI-compatible Provider，无业务层直接 SDK 调用。复用 AI_PROVIDER、AI_API_TYPE、AI_BASE_URL、AI_API_KEY、AI_MODEL 和平台 AI 开关。
- 发送的内容仅为当前主题课程说明、学习状态等级摘要及脱敏后的有限对话；不发送学生 ID、姓名、学号、邮箱、原始作答、隐藏测试用例或完整画像。
- 清理当前学生已知身份字段、邮箱、手机号、长编号和常见凭据，保留 Python 换行及缩进。自由文本脱敏不能保证识别所有隐含个人信息，UI 不应鼓励输入个人信息。
- 高置信度危险／隐私侵害／提示词覆盖及明确课程外请求在外发前拦截。其它语义范围由系统提示和结构化 status 处理，返回固定课程外或安全引导文案；正常 Python 文件操作与密码变量教学不直接当作危险。
- 情绪危机采用支持性回应并建议联系可信的人或紧急帮助，不提供危险方法。
- 模型输出严格 Zod 校验；最多重试一次，每次最多等待 12 秒并限制输出预算。失败、AI 关闭、Mock Provider 均明确显示课程基础帮助，不冒充完整答疑，也不提供练习跳转。
- QUESTION 阶段强制清空 advice；只有有效 ADVICE 回复才提供服务器生成的站内练习／测试链接。输出不执行代码、不渲染 HTML。
- 规则与模型约束不等同于对所有绕过方式的安全保证。仍需真实模型对抗用例验收；本次未增加全平台分布式限流、外部专用审核服务；已增加数据库持久化会话，重新登录后可访问自己仍有权限的课程记录。
