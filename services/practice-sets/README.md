# 练习组与练习中心

本次沿用 PersonalizedRecommendation.cycleKey，把同次推荐的题目完整组合；列表每次加载 20 个练习组，不把同组题目拆到不同分页。课程练习沿用 CourseRecommendationCycle，入口保留原链接，统一接入题号导航。历史记录没有明确课程关联时归为“通用个性化练习”，不根据题目标题猜课程。

作答页面支持上一题、下一题、直接跳题和已完成标记；访问过的题目组件保留挂载，切换时保留本页面的未提交答案。刷新或退出页面不保存未提交草稿。逐题提交仍调用原服务进行确定性判分、幂等处理、错题记录和掌握度更新。完成最后一题不会误认为整个练习组已完成。Python 判题成功后读取服务器结果更新完成进度。

新接口 GET /api/student/practice-sets 仅允许学生访问，按登录学生过滤每项数据库查询；查询使用共享 Zod 校验；输出只包含题目标题、类型、状态和安全知识点信息，不包含答案、解析或隐藏用例。所有历史记录、批次、成绩和证据保持原数据；没有 schema 或 migration 变更。
