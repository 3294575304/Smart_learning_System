# 练习组与练习中心

本次沿用 PersonalizedRecommendation.cycleKey，把同次推荐的题目完整组合；列表每次加载 20 个练习组，不把同组题目拆到不同分页。课程练习沿用 CourseRecommendationCycle，入口保留原链接，统一接入题号导航。历史记录没有明确课程关联时归为“通用个性化练习”，不根据题目标题猜课程。

作答页面支持上一题、下一题、直接跳题和已完成标记；访问过的题目组件保留挂载，切换时保留本页面的未提交答案。刷新或退出页面不保存未提交草稿。逐题提交仍调用原服务进行确定性判分、幂等处理、错题记录和掌握度更新。完成最后一题不会误认为整个练习组已完成。Python 判题成功后读取服务器结果更新完成进度。

新接口 GET /api/student/practice-sets 仅允许学生访问，按登录学生过滤每项数据库查询；查询使用共享 Zod 校验；输出只包含题目标题、类型、状态和安全知识点信息，不包含答案、解析或隐藏用例。所有历史记录、批次、成绩和证据保持原数据；没有 schema 或 migration 变更。

验证：推荐与课程推荐专项回归、新增分组/继续入口/状态/筛选/列表展示测试、TypeScript、相关 ESLint、Prettier 和 diff 检查。登录态浏览器、HTTP 数据库集成和生产构建未在本次完成。

## 2026-10-28 练习管理第一阶段

新增整组重命名、主动结束、单组／批量移入回收站和恢复。独立 PracticeSetManagement 表以 studentId + cycleKey 关联旧题组，首次操作或写入时创建管理记录，不回填历史成绩或学习证据。名称 1–80 字；批量至多 100 组，所有归属与修订号验证在同一事务内完成。

GET /api/student/practice-sets 增加 ACTIVE／HISTORY／TRASH 分区、关键词、课程和分页。PATCH /api/student/practice-sets/[id] 接受 RENAME／END／TRASH／RESTORE 与 expectedRevision；重命名附 title。POST /api/student/practice-sets/batch 接受 TRASH／RESTORE 与 items: [{id, expectedRevision}]。统一学生鉴权与已有响应格式，响应 private, no-store。

结束与删除对未完成题目标记 DISMISSED；恢复只恢复可见性，保留 endedAt。原始成绩、答案、错题、收藏和证据不删除。已受理 Python 判题可继续写回成绩，但题组结束状态独立保存，不能重新开放作答。

学生开始、客观题提交和 Python 提交与管理操作取得相同事务级题组锁；旧链接不能绕过已结束／回收站限制。管理界面提供确认弹窗、版本冲突刷新和批量原子性。回收站旧链接可只读查看与恢复。

本阶段提供管理所需的分区和基础列表入口；两个中心完整排版、浏览器前进后退恢复、复习面板收纳与专项浏览器验收仍属后续阶段。列表检索目前沿用服务层聚合，后续阶段继续处理按需加载与查询性能。

正式 migration 为 20261028130000_practice_set_management。回退保留表及管理状态，不删除记录；前一构建不能识别回收站元数据，因此故障回退只用于恢复服务，随后需重新部署管理功能。未完成题目已结束，不应通过回退恢复作答。
