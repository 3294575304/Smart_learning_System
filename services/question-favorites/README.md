# 学生题目收藏

收藏由学生主动添加，与系统错题本独立。同题可同时进入收藏和错题本；收藏、备注与取消操作不会改变成绩、错题状态、画像或知识掌握度。按钮位于题目操作区，练习中心的“我的收藏”采用紧凑分页列表，每页 20 条，支持课程、知识点、题型筛选及题目标题/个人备注搜索。

## 模型与历史兼容

StudentQuestionFavorite 使用学生—题目唯一关系，保存授权来源、课程、标题、题型及知识点快照。重复添加幂等且保留原备注。课程作业使用发布时的 Concept/来源节点快照，旧通用题目保留原 KnowledgePoint，不猜测历史课程。备注仅本人可见，最多 1000 字，revision 防止并发覆盖。取消带备注的收藏需确认，取消后备注一并删除。

迁移 `20261006200000_add_student_question_favorites` 只新增表、约束和索引，无历史回填、无成绩或证据修改。已应用本地开发库（共 57 个 migration）。回滚需先停止使用收藏入口并备份该表；删除新表会丢失收藏和备注，但不影响原题目、作答、错题和证据。

## 权限与再次练习

所有接口要求 STUDENT，资源查询按登录学生过滤。新增收藏必须来自本人可访问的推荐、作业题或错题；客户端不能指定学生身份。列表和详情不返回正确答案、隐藏用例或内部配置。收藏记录保留历史快照，题目停用、权限撤销、课程进度或图谱不匹配时标明不可练习并阻止启动。

“练习这道题”复用现有推荐、判分及课程证据链；有权限的进行中练习可继续，无进行中记录时创建新练习。显式收藏复习允许重复原题，仍经过审核题库、答案解析、课程权限、教学进度和正式图谱过滤。历史成绩与不可变 Concept 快照保持原状。简答题可收藏，但暂不进入自动判分的自主练习。收藏复习不计入正式课程成绩。

## 接口

- GET `/api/student/question-favorites`：本人列表及筛选选项。
- GET `/api/student/question-favorites/source`：授权作业来源解析。
- GET/PUT/PATCH/DELETE `/api/student/question-favorites/[questionId]`：状态、收藏、版本化备注、取消。
- POST `/api/student/question-favorites/[questionId]/practice`：UUID 幂等请求启动或继续练习。

输入共用严格 Zod Schema；使用既有统一响应与异常处理，响应 private/no-store。列表复用一次课程范围查询，避免每题重复权限数据库读取；收藏页签按需加载，切换不触发服务端页面导航。

## 验证

119 项推荐、课程推荐、错题与作业专项测试通过。独立 PostgreSQL 测试 schema 应用全量 migration 后验证唯一/幂等收藏、备注冲突、角色及跨学生隔离、筛选、安全字段、失效权限、取消与错题独立、通用/课程再次练习与历史快照保持。Edge 无头真实组件验证按需加载、收藏状态同步、备注保存、练习跳转及带备注取消，无页面异常；API 使用模拟响应，该测试不等于登录态整页端到端验收。类型、相关 Lint 及生产构建通过。
