# 学生端流程与界面自检（2026-10-07）

本次沿学生学习闭环检查学习主页、课程列表/课程学习中心/图谱/画像、任务/作业/签到/问卷、成绩/分析、练习/收藏/错题的主要入口与状态。复用既有权限、题库、作答、判分和追加式证据链，没有数据库迁移、历史回填或成绩/证据改写。未提交的教师端和其他模块修改予以保留。

## 发现与处理

| 问题                                                         | 修正                                                                                         |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| 首页任务卡与待完成作业列表重复                               | 合并为任务卡，条目直接进入作答或问卷                                                         |
| 已提交后开始重做仍显示已提交、从待办消失                     | 作业列表及首页计数识别进行中的重做；未开始重做不自动成为待办                                 |
| 过期草稿被列为进行中                                         | 无已提交成绩时，超时草稿显示已截止；已提交记录仍保留已提交状态                               |
| 学习任务读取全部出勤历史和修订后再过滤                       | 复用首页窄查询，只读取本人当前有效窗口的待签到场次；继续检查班级活跃状态和成员归属           |
| 签到按钮只看 OPEN、不看时间窗口                              | 使用与服务端一致的开闭时间判断；未开放/已结束显示具体状态，每 15 秒更新                      |
| 签到没有 pending、网络失败恢复和成功反馈                     | 防重复请求；统一 requestApi；成功后显示服务器正常/迟到状态；刷新失败可单独重试，避免重新签到 |
| 自主练习按钮落到默认列表                                     | 显式带 view=generate 与课程 ID                                                               |
| 课程练习/收藏/作答缺少对应侧栏高亮、面包屑指向不存在的中间页 | 关联主导航，虚拟根面包屑返回练习/收藏/作业或成绩入口                                         |
| 课程卡片把全部可练知识点称为教学进度                         | 改为可练范围；不改变已授过滤或当前自主练习策略                                               |
| 学习分析与我的课程重复大卡片、旧链路与正式画像混淆           | 课程入口采用紧凑链接；旧题目结果标记为历史参考；内部趋势枚举改为中文                         |
| 学情评估文案难懂                                             | 显示尚未评估/待进一步评估；保留证据门槛，不凭少量数据赋予熟练等级                            |
| 截止问卷写成未开放                                           | 区分已截止和未开放                                                                           |
| 错题卡片过大、筛选重置后搜索框残留                           | 紧凑列表、错误细节折叠，搜索框随查询参数同步                                                 |

## 统一界面

学生专用 StudentPageHeader 复用现有标题组件并增加统一卡片容器；覆盖主页、课程、任务、作业、签到、问卷、成绩、分析和错题等主要页面，不改变教师/管理员标题组件。学生主内容区统一最大宽度与最小宽度约束，适配已有练习中心排版。课程内导航保留课程上下文，收藏与错题职责分离；loading、error 页面继续沿用既有恢复机制。

## 验证与边界
