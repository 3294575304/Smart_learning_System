# 智学课堂 MVP 状态与验收指南

## 当前状态

智学课堂 MVP 已完成管理员、教师和学生三类角色的核心教学闭环：

1. 教师创建班级和私有题目。
2. 教师创建并发布包含客观题和主观题的作业。
3. 学生加入班级，开始作业，自动保存并提交。
4. 系统自动批改客观题，教师人工批改主观题。
5. 教师完成批改并正式发布成绩。
6. 学生查看总分、逐题得分、参考答案、解析和教师反馈。
7. 系统生成学情分析和个性化推荐。
8. 学生完成推荐练习并查看服务端判分。
9. 系统维护错题本，学生可以更新掌握状态。
10. 管理员治理公共题库和异常班级，并查看审计记录。

## 已完成功能

### 账号与权限

- 邮箱密码登录和学生自主注册。
- 数据库存储会话，浏览器只保存 `HttpOnly` 会话 Cookie。
- `ADMIN`、`TEACHER`、`STUDENT` 角色路由保护。
- API 身份、角色、资源归属和 Zod 输入校验。
- 未登录统一返回 `401`，角色不符返回 `403`。
- 跨教师资源返回 `404`，避免泄露资源是否存在。

### 管理员

- 平台仪表盘、用户管理和审计日志。
- 系统配置、维护模式和系统健康状态。
- 系统公告和站内通知。
- 公共题库查询、设置公共、撤销公共和停用题目。
- 班级查询、详情和异常班级软关闭。
- 关键治理操作写入不可编辑的审计记录。

### 教师

- 创建、编辑、关闭班级，管理邀请码和学生。
- 创建、编辑、复制、删除或归档私有题目。
- 查看并复制公共题目。
- 创建作业、选择题目、设置分值和发布作业。
- 查看学生提交并批改主观题。
- 完成整份批改并正式发布成绩。
- 查看班级平均分、分数分布、题目和知识点正确率。

### 学生

- 注册或登录、通过邀请码加入班级。
- 查看作业、开始作答、自动保存和刷新恢复。
- 提交作业，并在成绩发布前隐藏正式成绩和答案。
- 成绩发布后查看总分、逐题得分、解析和教师反馈。
- 查看学情分析和个性化推荐原因。
- 开始、提交推荐练习并查看服务端判分。
- 查看错题本、重新练习和更新掌握状态。

### AI 与降级

- 业务代码通过统一 AI Service Layer 调用 Provider。
- AI 输出使用严格 JSON Schema 和 Zod 校验。
- Provider 失败重试一次，仍失败时使用规则分析。
- AI 故障不会阻塞交卷、批改或成绩查看。
- 本地可使用 `mock` Provider；生产环境可使用 OpenAI-compatible Provider。

## 角色权限摘要

| 能力           | 管理员     | 教师                   | 学生                   |
| -------------- | ---------- | ---------------------- | ---------------------- |
| 用户和系统配置 | 管理       | 无权访问               | 无权访问               |
| 公共题库治理   | 管理       | 只读和复制             | 无权访问               |
| 班级           | 平台治理   | 仅管理自己的班级       | 仅访问已加入班级       |
| 私有题目       | 平台治理   | 仅管理自己的题目       | 无权访问               |
| 作业和提交     | 平台统计   | 仅管理自己的作业和提交 | 仅访问自己的作业和提交 |
| 成绩           | 平台统计   | 仅发布和查看自己的班级 | 仅查看自己的已发布成绩 |
| 推荐和错题     | 不直接操作 | 受控生成               | 仅访问和更新自己的记录 |

## 环境要求

- Node.js 20.9 或更高版本。
- npm 10 或更高版本。
- PostgreSQL 14 或更高版本。

## 环境变量

复制 `.env.example` 为 `.env`，并配置以下变量：

| 变量                                           | 用途                          | 要求                                       |
| ---------------------------------------------- | ----------------------------- | ------------------------------------------ |
| `DATABASE_URL`                                 | 开发或运行数据库              | 必填                                       |
| `TEST_DATABASE_URL`                            | 自动化集成测试数据库          | 必填；必须是独立数据库，名称含 `test`      |
| `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD`     | 本地管理员种子账号            | 仅本地使用，生产必须修改                   |
| `SEED_TEACHER_EMAIL` / `SEED_TEACHER_PASSWORD` | 本地教师种子账号              | 仅本地使用，生产必须修改                   |
| `SEED_STUDENT_EMAIL` / `SEED_STUDENT_PASSWORD` | 本地学生种子账号              | 仅本地使用，生产必须修改                   |
| `AI_PROVIDER`                                  | `mock` 或 `openai-compatible` | 本地可用 `mock`                            |
| `AI_MODEL`                                     | AI 模型名称                   | 使用真实 Provider 时必填                   |
| `AI_BASE_URL`                                  | OpenAI-compatible API 地址    | 使用真实 Provider 时必填                   |
| `AI_API_KEY`                                   | AI API 密钥                   | 使用真实 Provider 时必填                   |
| `AI_TIMEOUT_MS`                                | 单次 AI 请求超时              | 可选，默认使用安全值                       |
| `AI_PSEUDONYM_SALT`                            | 学生匿名标识盐值              | 生产模式必填，至少使用不可预测的独立随机值 |
| `NOTIFICATION_JOB_SECRET`                      | 作业提醒内部任务密钥          | 必填，建议至少 32 个随机字符               |

不要提交 `.env`、真实密钥或生产数据库连接。

## 数据库迁移

初始化本地数据库：

```bash
npm install
npm run db:setup
```

等价的分步命令：

```bash
npm run prisma:generate
npm run prisma:migrate
npm run prisma:seed
```

部署环境使用已提交的迁移，不要直接修改生产数据库：

```bash
npx prisma migrate deploy
```

检查 Schema 和迁移状态：

```bash
npx prisma validate
npx prisma migrate status
```

## 本地启动

```bash
Copy-Item .env.example .env
npm install
npm run db:setup
npm run dev
```

访问 `http://localhost:3000`。

## 测试命令

```bash
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
npm run test:http-integration
npx prisma validate
npx prisma migrate status
```

`npm run test:http-integration` 使用 `TEST_DATABASE_URL`。测试运行器会：

1. 校验测试数据库与开发数据库不同。
2. 拒绝生产或预发布目标。
3. 在测试数据库创建唯一隔离 Schema。
4. 应用全部迁移并执行 Seed。
5. 启动生产构建，执行身份、权限、资源隔离和业务流程测试。
6. 测试完成后删除隔离 Schema。

建议单独创建例如 `smart_learning_test` 的本地 PostgreSQL 数据库，禁止把生产数据库配置为测试库。

## 演示流程

### 管理员

1. 登录 `admin@example.com`。
2. 查看平台仪表盘、用户、审计和系统配置。
3. 打开公共题库，设置或撤销公共题目。
4. 打开班级治理，查看详情或关闭异常班级。
5. 回到审计日志确认治理记录。

### 教师

1. 登录 `teacher@example.com`。
2. 创建班级并记录邀请码。
3. 创建私有客观题或主观题。
4. 创建包含两类题目的作业并发布。
5. 等待学生提交后进入“批改提交”。
6. 保存主观题评分，完成整份批改。
7. 正式发布成绩并查看成绩统计。

### 学生

1. 登录 `student@example.com`，或在开放注册时创建学生账号。
2. 使用教师邀请码加入班级。
3. 开始作业并填写答案，等待“已自动保存”。
4. 刷新页面确认答案恢复，然后提交。
5. 成绩发布后查看总分、逐题结果和教师反馈。
6. 进入推荐练习，生成、开始并提交练习。
7. 查看错题本并维护掌握状态。

## 已知限制

- 当前仅支持站内通知，不支持邮件、短信、微信、移动推送、WebSocket 或 SSE。
- 作业截止提醒需要部署平台定时调用内部任务接口，仓库不包含常驻调度器。
- `mock` AI Provider 用于本地可重复测试，不代表真实大模型效果。
- 学情分析对知识点名称的展示仍有改进空间；底层分析和推荐使用稳定知识点 ID 保证数据一致性。
- 自动保存使用服务端存储，浏览器 `localStorage` 仅作为未完成作答的本地恢复兜底，退出登录时会清理。

## 非 MVP 功能

以下能力不属于当前 MVP：

- 视频课堂和直播。
- 家长端。
- 支付和订阅。
- 社交、私信和社区。
- 复杂知识图谱。
- 邮件、短信和移动端推送。
- 多租户学校组织和跨校数据分析。
