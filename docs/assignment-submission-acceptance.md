# 作业发布与学生提交验收说明

## 1. 启动准备

```bash
npm install
npx prisma migrate deploy
npm run prisma:seed
npm run dev
```

演示账号：

- 教师：`teacher@example.com` / `Teacher123!`
- 班内学生：`student2@example.com` / `Student123!`
- 未入班学生：`student3@example.com` / `Student123!`

## 2. 教师验收流程

1. 使用教师账号登录，进入“作业管理”。
2. 点击“创建作业”，填写名称、说明并选择“初一数学一班”。
3. 设置当前时间之前或附近的发布时间，以及未来的截止时间。
4. 从题库加入单选、多选、判断、填空和简答题。
5. 使用“上移/下移”调整题序，修改每题分值。
6. 先点击“保存草稿”，确认列表状态为“草稿”，重新进入后内容保持不变。
7. 编辑题库中的某道题，再返回草稿并点击“发布作业”。发布时应重新生成最新快照。
8. 发布后作业状态变为“已发布”，不再显示编辑入口。
9. 再次修改来源题目，确认学生端已发布作业的题干、选项和批改答案保持不变。

## 3. 学生验收流程

1. 使用班内学生登录，进入“我的作业”。预约时间未到的作业不可见，到达发布时间后可见。
2. 打开作业详情，核对题目顺序、分值、截止时间和历史提交记录。
3. 点击“开始作答”，填写各种题型答案。
4. 停止输入约一秒，顶部应从“保存中”变为“已自动保存”。刷新页面后答案仍存在。
5. 断开网络后修改答案，应显示“自动保存失败”，答案保留在当前页面和浏览器临时备份中；恢复网络后点击“重试”。
6. 点击“提交作业”并确认，页面进入结果页。
7. 结果页显示提交时间、客观题逐题得分和当前总分；简答题显示“待人工批改”。
8. 若允许重复提交，返回作业详情可以开始下一次作答，提交记录保留每次尝试。
9. 若不允许重复提交，首次提交后不再显示开始按钮。

## 4. 核心测试用例

| 编号 | 场景                                | 预期结果                                     |
| ---- | ----------------------------------- | -------------------------------------------- |
| A01  | 未登录访问教师作业 API              | 返回 401                                     |
| A02  | 学生调用教师创建作业 API            | 返回 403                                     |
| A03  | 教师选择其他教师班级                | 返回 404，不泄露班级信息                     |
| A04  | 教师选择无权使用的私有题            | 创建或发布失败                               |
| A05  | 发布时间晚于或等于截止时间          | Zod 校验失败，返回 400                       |
| A06  | 空题目草稿执行发布                  | 返回 400，草稿仍保留                         |
| A07  | 修改已发布作业                      | 返回 403，快照不变                           |
| A08  | 发布后修改题库来源题                | 学生看到的题目和批改标准不变                 |
| S01  | 未入班学生访问作业详情              | 返回 404                                     |
| S02  | 被移除/已退出学生保存答案           | 返回 404                                     |
| S03  | 预约发布时间未到                    | 作业列表不可见、详情返回 404                 |
| S04  | 截止时间到达后保存或提交            | 返回 409                                     |
| S05  | 答案包含其他作业题目或选项          | 返回 400                                     |
| S06  | 两个旧版本自动保存并发              | 仅首个成功，旧版本返回 409                   |
| S07  | 自动保存网络失败                    | 明确失败提示、本地保留答案、允许重试         |
| G01  | 多选正确选项以不同顺序提交          | 按集合判定正确并获得满分                     |
| G02  | 多选漏选、多选或加入错误选项        | 判定错误并记 0 分                            |
| G03  | 填空答案含首尾/连续空格且大小写不同 | 默认归一化后正确                             |
| G04  | 填空题启用大小写敏感                | 大小写不同判定错误                           |
| G05  | 简答题提交                          | 逐题状态为待人工批改，总分显示客观题当前得分 |
| C01  | 快速双击提交                        | 两个请求返回同一提交结果，只记录一次提交时间 |
| C02  | 同一开始作答幂等键重试              | 返回同一个进行中尝试                         |
| C03  | 禁止重复提交时再次开始              | 返回 409                                     |
| C04  | 允许重复提交时再次开始              | 创建递增的 `attemptNumber`，历史结果不覆盖   |

## 5. 自动化验证命令

```bash
npm test
npm run build
npm run test:integration
```

作业 HTTP 集成测试会自动验证认证、教师资源归属、题目快照、班级隔离、自动保存版本冲突、多选顺序、填空空格、双击提交、重复尝试和截止时间，并在结束后清理临时数据。
