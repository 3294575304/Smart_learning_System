## 本轮确认的重要产品口径

- 任务、签到、作业与成绩按教学班管理；跨班课程画像标记课程汇总，同名课程或共享模板不使教学班隐式合并。
- 自主练习覆盖所属课程当前正式图谱，可预习未授内容；自动推荐保留独立授课进度策略。正式绑定、审核题库、权限、难度与隐藏用例隔离仍有效。
- 普通练习可设置 1–50 题，库存不足时说明实际数量；综合测试保持原 50 题和配比，题量不足不生成残缺测试。
- 既有推荐练习组为逐题串行提交，可能部分成功；选择/判断必答，支持的空白答案确定性记零，非空简答无自主评分时明确拦截，编程排队/系统错误不当最终零分。
- 该练习组的会话草稿恢复不等于所有新旧练习链路均已支持跨设备持久化恢复。确认恢复后仍以服务端状态为准。
- 未评估不等于零分；章节参考熟练度、稳定掌握度、整组得分率各自说明范围。当前采用已有客观数据条形图，不补造六维能力。
- 固定格式成绩表导出入口和旧格式请求已移除；十列导入兼容保留。主要导出与报告工作簿共用正式快照，未发布修改不进入正式文件。
- 问卷待开放与待完成分开；发布通知不意味着已经可填写。预约详情说明时间，开放后才计入待处理。
- 报告课程总结覆盖教学支撑、考核一致性/评分标准、目标达成、自评比较；实际授课方式与评分细则来自教师事实输入，不从成绩推测。
