## 已确认的质量基线

最近一次全项目复验日期为 2026-08-20，而不是本状态文档的更新时间。实际记录为：

- 自动化测试 376 项：375 项通过，1 项因未配置固定外部 PDF 路径跳过。
- 53 个 migration 的空库 HTTP 集成通过。
- 推荐/通知 PostgreSQL 集成 14/14 通过。
- 格式、Lint、类型检查、Prisma 校验、Next.js 生产构建、沙箱执行器构建和判题 worker 构建通过。
- 迭代七固定报告样例已由 Microsoft Word 打开并导出为 7 页 PDF，逐页检查未发现裁切、重叠、破表、缺字或签字区误填。

2026-08-31 的工作是仓库与文档状态核对，没有重新运行上述全量门禁。因此，在新的执行记录产生前，不增加测试数量、不变更专项验收结论，也不宣称 V1.0 已完成。

## 当前关键路径

1. 完成迭代七专项验收：登录态实名/匿名问卷、真实 AI Provider、教师修改确认和正式报告下载。
2. 实施迭代八 A：持久化长任务 worker、安全响应头、限流和电子表格解析预算。
3. 实施迭代八 B：三角色 Playwright E2E、隔离测试环境和 CI 门禁。
4. 实施迭代八 C：整合教师课程分析中心与学生学习中心，统一导航和异步状态。
5. 实施迭代八 D：结构化日志、指标告警、数据留存、私有文件生命周期和部署恢复演练。
6. 执行迭代八 E：固定样本、真实 AI、真实沙箱、三角色浏览器和故障降级的 V1.0 总验收。

顺序约束：先完成迭代七验收，再处理可靠性与安全 P0；E2E/CI 门禁建立后再封口界面与部署；只有全部发布门禁形成可核验记录，才把 V1.0 标记为完成。

## 主要未闭环风险

- 大纲解析、知识图谱、题目批量映射和质量报告仍缺少统一的持久化独立 worker，Web 进程中断恢复能力未完成。
- 登录、注册、上传和高成本 AI 接口的系统化限流，以及全局安全响应头和电子表格解压预算未完成。
- 三角色登录态 E2E 与 CI 尚未成为发布门禁，界面流程仍需整合。
- 真实 AI Provider、长期运行监控、数据留存、备份恢复和目标环境部署演练尚无 V1.0 总验收记录。
