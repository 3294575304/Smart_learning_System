## 2026-09-07 实跑质量证据

- 格式、Lint、类型检查、Prisma 校验和开发库 migration 状态通过；54 个 migration 已全部应用。
- 自动化测试 386 项：385 项通过、0 失败、1 项因未配置固定外部 PDF 路径 `SYLLABUS_ACCEPTANCE_PDF_PATH` 跳过。
- Next.js 生产构建、沙箱执行器、编程判题 worker 和持久化长任务 worker 构建通过。
- 推荐/通知 PostgreSQL 集成 14/14 通过。
- 空库 HTTP 集成成功应用 54 个 migration，并通过认证、管理员和班级阶段，但课程大纲用例仍按旧同步 `201/SUCCEEDED` 契约断言；当前接口按持久化 worker 设计返回 `202/PENDING`，且测试运行器没有启动/等待独立 worker，因此全套失败。本次已修复测试清理未删除新增 `BackgroundJob` 外键的问题，但异步编排缺口仍待解决。

因此，2026-09-07 不是“全量门禁全部通过”日期。迭代七、迭代八 A 和 V1.0 的验收状态均不提升。

该记录早于第 54 个 migration 和持久化 worker，不能替代当前异步架构下的空库 HTTP 集成复验。

## 当前关键路径

1. 修复空库 HTTP 集成编排：启动独立 worker，按 `202/PENDING → 终态` 验证四类长任务并恢复全套通过。
2. 完成迭代七专项验收：登录态实名/匿名问卷、真实 AI Provider、教师修改确认和正式报告下载。
3. 继续迭代八 A：完成独立 worker 目标环境重启/租约接管演练，并实施安全响应头、限流和电子表格解析预算。
4. 实施迭代八 B：三角色 Playwright E2E、隔离测试环境和 CI 门禁。
5. 实施迭代八 C：整合教师课程分析中心与学生学习中心，统一导航和异步状态。
6. 实施迭代八 D：结构化日志、指标告警、数据留存、私有文件生命周期和部署恢复演练。
7. 执行迭代八 E：固定样本、真实 AI、真实沙箱、三角色浏览器和故障降级的 V1.0 总验收。

顺序约束：先恢复异步长任务的 HTTP 集成门禁，再完成迭代七验收并封口可靠性与安全 P0；E2E/CI 门禁建立后再封口界面与部署；只有全部发布门禁形成可核验记录，才把 V1.0 标记为完成。

## 主要未闭环风险

- 四类长任务已接入统一持久化独立 worker，但 HTTP 集成仍按旧同步契约运行，目标环境进程重启、租约接管和产物一致性的部署演练也尚未形成专项验收记录。
- 登录、注册、上传和高成本 AI 接口的系统化限流，以及全局安全响应头和电子表格解压预算未完成。
- 三角色登录态 E2E 与 CI 尚未成为发布门禁，界面流程仍需整合。
- 真实 AI Provider、长期运行监控、数据留存、备份恢复和目标环境部署演练尚无 V1.0 总验收记录。
