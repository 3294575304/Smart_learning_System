# 迭代四验收记录

日期：2026-08-07

## 实现范围

- 从当前正式 v3 教学大纲及其正式 PDF 来源提取课程目标、考核项目、课程目标分配比例和达成阈值，生成可审核、乐观并发、显式发布且不可变的考核方案版本。
- 建立课程/班级/正式方案版本上下文的成绩台账；支持正式平台作业同步、人工修正、精确总评、不可变成绩发布及学生只读查询。
- 兼容真实固定成绩模板：唯一可见工作表 `sheet`，A-J 十列固定表头，学号按文本匹配；支持 `.xls`/`.xlsx` 严格预览、幂等执行和同结构 `.xlsx` 导出。
- 实现签到场次、服务端时间窗口、幂等学生签到、结束结算缺勤、教师带原因纠正及逐场出勤统计。
- 基于正式教学大纲目标、正式方案映射和正式成绩发布证据生成版本化课程目标达成度，可下钻学生和考核项目证据。

## 确定性口径

- Decimal 中间值保留 4 位，总评和出勤率最终保留 2 位，均采用 ROUND_HALF_UP。
- 总评：项目先换算百分制，项目权重汇总为组件分，组件按正式方案权重汇总。数值 0 是有效成绩；缺考/作弊按 0 参与；尚未录入、缓考、请假和其他为未完成；免修从分母剔除并重归一。
- 模板 G 列是正式课程总评覆盖，不作为课程目标达成度证据；H 列保存特殊状态。
- 出勤：正常 1、迟到 0.8、早退 0.8、缺勤 0；请假、待确认和取消场次不进入分母。
- 单生目标分：按 `组件课程权重 × 教学大纲目标分配比例` 加权归一；缺失映射证据排除，免修组件从分母剔除。班级目标分为参与学生均值；阈值来自正式大纲派生方案，样本为 60 分，达成指数为均值/阈值。

## 版本、权限与审计

- 正式方案、成绩发布和达成度运行均追加版本，使用 Restrict 保护历史证据；来源正式大纲结构、规则版本、输入快照和 SHA-256 指纹均保存。
- 相同输入发布/生成幂等复用；草稿和出勤修正使用 revision 检测并发。新成绩发布后旧达成度显示过期，不静默覆盖。
- 教师资源同时校验课程和班级归属；学生只能查询自己的已发布成绩和出勤。跨教师/跨课程资源使用既有 404 防枚举语义。
- 方案发布、成绩发布/导入/修正、签到状态和纠正、达成度生成均使用事务并写现有审计日志。

## 明确边界

- 未实现 Python 沙箱、OCR、定位/人脸/二维码签到、完整画像、问卷、DOCX 报告、在线审批和外部通知。
- 导出使用固定十列结构的 `.xlsx`；不会伪造原始旧版 `.xls` 二进制格式，也不改写真实上传样本。
