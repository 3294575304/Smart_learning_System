# 迭代六实施记录

> 更新时间：2026-08-12
> 状态：已完成并通过专项验收

## 收尾实现（2026-08-12）

- 扩展既有 Python `ProgrammingAttempt` 为作业来源或推荐来源二选一，继续复用后台任务、租约、远程隔离执行、隐藏用例和系统故障重试；推荐结果不创建作业或正式成绩。
- 推荐 Python 重判与撤销生成新 Attempt、学习事件和 Concept 证据修订，不覆盖旧证据；同分重判也以评测修订键追加历史，撤销后重算掌握度和画像。
- 增加教师教学进度页面、学生课程图谱自主练习页面与结构化条件确认，覆盖知识点、题型、题量和难度。
- 增加独立 `StudentSelfReflection`，支持 AI 严格结构化、规则降级、学生修改确认和软删除；自述不覆盖客观掌握度。
- 六项推荐权重形成不可变策略修订并校验合计 100%；确定性排序实际消费掌握缺口、先修缺口、难度、近期错误、题目新鲜度和 `teacher-priority` 标签。
- 旧 MVP 推荐、旧作业、历史推荐和证据均不回填、不改写。

## 第二批实现（2026-08-12）

第二批完成客观推荐练习的课程证据回写闭环：

- 生成课程推荐时冻结题目—Concept 绑定修订、来源图谱/节点和当前正式图谱解析节点，后续教师修改题目绑定不会改写历史推荐。
- 新增独立的追加式 `RecommendationConceptEvidence`，不伪造作业、提交或正式成绩记录。
- 扩展统一学习事件来源，客观推荐作答生成 `RECOMMENDATION_PRACTICE_GRADED` 事件；事件明细必须且只能引用作业快照或推荐快照之一。
- 在同一 Serializable 事务内完成推荐状态、答案、错题、旧 MVP 掌握度、课程事件、课程 Concept 证据、掌握度修订和画像快照，任一步失败均整体回滚。
- 课程掌握度同时聚合有效作业证据和推荐练习证据，指纹包含来源类型与来源答案，避免跨来源 ID 误去重。
- 画像证据下钻可读取推荐练习来源；下一次课程推荐会自然引用最新掌握度修订和画像快照。
- 迁移保持增量，不回填旧推荐；旧 MVP 推荐仍按原链路运行。

本节为第二批历史记录；上述能力已在收尾实现中补齐。

## 本批范围

本批先完成课程图谱驱动推荐的数据基座和确定性结构化生成接口，不把旧全局知识点掌握度继续带入课程推荐，也不伪造作业证据。

已实现：

- 版本化教学进度和已授 Concept 明细。
- 默认推荐策略修订，保存规则版本、权重、近期窗口、难度容差和题量上限。
- 课程推荐周期，冻结正式图谱、画像快照、掌握度修订、教学进度、规则修订和结构化请求。
- 推荐项保存稳定 Concept、排序分数和原因码。
- 教师教学进度查询/更新 API，包含归属、图谱版本、乐观并发和审计校验。
- 学生课程推荐生成 API，包含学生本人、课程班级成员、正式图谱和教学进度校验。
- 候选硬过滤：课程绑定、当前图谱可解析、已授范围、启用状态、解析、支持题型、难度、近期完成和有效在途推荐。
- 证据不足冷启动理由，不把无证据或少量证据描述为未掌握。
- 加法式 migration；旧 `PersonalizedRecommendation` 历史保持兼容，不回填。

## 当前边界（第二批时的历史状态）

- 当前课程推荐练习只生成已有同步自动批改题型；Python 编程题将在复用异步判题 Attempt 后接入。
- 推荐练习结果尚未投影为课程 `LearningEvent` 和追加式课程 Concept 证据，因此尚不能声明完整反馈闭环完成。
- 教学进度和结构化自主练习尚未完成页面整合。
- AI 自述、自然语言条件转换和反思证据 CRUD 尚未实现。
- 先修关系、错误类型和教师优先级已保留策略权重，但首批排序只启用掌握缺口、难度适配和新鲜度；不得将其描述为完整排序能力。
