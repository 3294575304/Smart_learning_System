# V1.0 迭代一验收与使用指南

> 范围：课程模型、教学大纲上传与学生名单导入基础
>
> 当前账号方案：预导入学生身份，学生使用唯一学号自主认领
>
> 计划书基线：《项目计划书》2.1 版

## 1. 验收范围

本迭代验收：

- Python 程序设计课程模板、教师课程和班级关联。
- 教学大纲 PDF 上传、查看、替换和所有权隔离，不包含 AI 解析。
- 固定 10 列 XLS、同表头 XLSX 及兼容 CSV 的名单上传、版本、映射和预览。
- 待认领学生身份、班级预分配、学生自主认领和自动入班。
- 导入与认领的事务回滚、幂等、并发控制和安全错误响应。
- 原 MVP 核心闭环回归。

教学大纲结构化解析、知识图谱、成绩与达成度、签到、Python 在线判题、画像增强、结课问卷和教学质量报告不属于本迭代。

## 2. 当前权威账号流程

1. 教师上传名单并确认字段映射。
2. 系统在正式导入事务中：
   - 匹配已有学生账号并加入班级；
   - 为未注册学生创建唯一 `StudentIdentity`；
   - 创建 `StudentIdentityClassroomAssignment` 班级预分配关系；
   - 不创建默认密码账号。
3. 学生在 `/register` 输入学号、名单姓名、邮箱和自设密码。
4. 系统校验学号存在、姓名匹配、身份未认领和邮箱未注册。
5. 系统在同一事务中创建 `STUDENT` 用户、绑定身份、更新认领状态并建立全部预分配班级成员关系。
6. 重复或并发认领只允许一个请求成功；事务失败不保留用户、认领状态或成员关系的部分写入。

历史一次性账号、账号表下载和首次改密能力只兼容旧账号，不用于新名单导入。新导入流程不生成、展示或下载初始密码。

## 4. 名单模板

固定模板包含 1 个工作表和以下 10 列：

1. 学年学期(文本)
2. 课程号(文本)
3. 学号(文本)
4. 姓名(文本)
5. 班级(文本)
6. 成绩标识(文本)
7. 期末成绩(100.0%)(文本)
8. 特殊原因(文本)
9. 等级成绩类型(文本)
10. 备注(文本)

学年学期、课程号、学号、姓名和班级是本迭代必填字段。学号按文本读取；数值单元格、科学计数法、缺失值、文件内重复学号和非法格式产生阻断错误。后 5 个成绩字段保留在导入暂存数据中，不在本迭代导入成绩。

## 5. 导入和注册演示

1. 管理员确认 Python 程序设计模板已启用。
2. 教师创建班级，并使用 Python 模板创建课程。
3. 教师关联自己的班级。
4. 教师上传教学大纲 PDF，查看文件信息，并上传新版本完成替换。
5. 教师进入学生名单管理，上传固定模板 XLS 或 XLSX。
6. 教师确认工作表、表头、字段映射和逐行预览。
7. 教师处理所有阻断错误后执行正式导入。
8. 结果页展示新增待认领身份、匹配已有账号、已入班、跳过和失败数量。
9. 使用名单中的学号与姓名在 `/register` 注册。
10. 验证学生注册后自动进入名单预分配的课程班级。
11. 重复导入同一名单，确认不重复创建身份或成员关系。

## 6. 权限和安全

- 管理员管理课程模板；教师只读取启用模板。
- 教师只能管理自己的课程、班级、文件和导入批次。
- 跨教师资源统一返回 404；未登录返回 401；角色不符返回 403。
- 名单预览不创建用户、身份或课程成员。
- 正式导入和注册使用事务，失败不会留下未知中间状态。
- API 不返回 Prisma 堆栈、存储绝对路径、密码哈希或第三方原始错误。
- 学生注册角色固定为 `STUDENT`，额外角色字段会被拒绝。
- 新名单导入不生成默认密码或明文账号表。

## 7. 已知限制

- 默认名单文件上限为 5 MB、最多 1000 条，可由安全环境变量在受控范围内调整。
- CSV 只接受 UTF-8；固定验收格式仍为 XLS/XLSX。
- 隐藏工作表、公式单元格和合并单元格会阻断导入。
- 名单执行当前在受控请求内同步完成，尚未后台任务化。
- `createdUserRows` 是历史字段名，当前响应语义为“新增待认领身份数”。
- 历史一次性账号字段、导出工具和下载端点暂留兼容；新批次不会产出可下载账号表。

## 9. 数据库和回滚说明

- `20260731120000_add_student_identity_claim_registration` 新增学生身份、班级预分配及唯一约束，并把已有唯一学号用户回填为已激活身份。
- 原有用户、班级、作业、提交、成绩、分析、推荐和通知数据不删除。
- 名单正式执行使用 Serializable 事务；失败时正式数据整体回滚，并保存脱敏失败状态和审计信息。
- 注册在一个事务内创建用户、认领身份和建立班级成员关系。
- 教学大纲替换先保存新文件；数据库事务失败时清理新文件，事务成功后再清理旧文件。
