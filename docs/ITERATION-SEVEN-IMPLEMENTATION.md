# V1.0 迭代七实现记录

> 日期：2026-08-16  
> 状态：功能闭环已实现，待专项验收

## 实现范围

- 正式教学大纲派生结课问卷草稿，包含课程目标自评、教学内容、教学方法、考核方式、学习支持、实践能力和开放题。
- 教师逐题审核、时间设置、实名/匿名模式、乐观并发保存、发布冻结、关闭和聚合结果界面。
- 学生问卷列表、五级量表与开放题作答、必答校验、提交二次确认、一次性幂等提交和历史完成状态。
- 发布复用课程班级成员与站内通知；问卷不进入作业计分、成绩台账、知识证据或推荐闭环。
- 匿名参与与回答物理隔离：`CourseSurveyParticipation` 不保存回答外键，匿名 `CourseSurveyResponse.studentId` 为 `NULL`，匿名提交不写入可关联回答的实名审计。
- 小于 5 份回答时只保留人数和响应率；达到阈值后确定性计算题目、维度和课程目标均值/分布，并保存输入指纹与不可变汇总修订。
- 开放题清理邮箱、手机号、学号等显式个人标识，只输出共性主题计数和聚合文字，不向教师返回单份匿名回答。
- 教学质量报告自动冻结同班级最近一次已关闭问卷的聚合快照；学生自评与客观成绩/课程目标定量达成度分开表述。
- 报告文字通过统一 AI Service Layer 生成，只发送去标识化聚合；Provider 缺失、关闭、超时或输出无效时使用确定性降级。

## 数据与迁移

- 新增第 50 个 migration：`20260816100000_add_course_surveys`。
- 新增问卷、问题、参与、回答、答案和汇总修订模型，以及审计和通知枚举。
- migration 为追加式，不回填、不删除、不改写历史课程、成绩、作业、画像、推荐或报告数据。
- 回滚策略：在尚无正式问卷数据时可删除第 50 个 migration 新增表和枚举值；已有数据后应先导出问卷与汇总快照，不执行破坏性自动回滚。

## 权限与隐私

- 所有教师入口同时校验角色、课程归属、班级归属和问卷状态；跨教师资源返回统一不存在语义。
- 所有学生入口校验角色、有效班级成员关系、开放/截止时间和参与状态。
- 匿名回答没有教师可用的身份关联；报告只消费 `CourseSurveySummaryRevision`，不读取单份回答。
- 外部 AI 输入不含姓名、学号、邮箱、手机号或单份开放题，只包含课程聚合统计和已脱敏主题。
