# 课程教学质量分析报告模板（2024 版）保真契约

## 权威来源

- 仓库资产：`assets/report-templates/quality-report-2024.docx`
- 原始文件：`课程教学质量分析报告模板(2024版）.docx`
- SHA-256：`659ed18e3577332acd6ade374c7bd477e272218285ee78ae3013017e96dd8c54`
- 参考成品：`计算机程序设计（Python）III-教学质量分析报告.docx`
- 模板页数：6 页（封面 1 页，正文页码 1–5）
- 模板结构：2 个 A4 纵向节、8 个顶层表格、页眉校名与建筑图、正文页脚页码域。

生成前必须校验仓库资产哈希。哈希不一致时直接失败，不得使用近似模板或重新绘制版式。

## 页面系统

- 页面：A4 纵向，约 8.27 × 11.69 英寸。
- 页边距：左约 0.98 英寸，右约 1.02 英寸，上下约 0.47 英寸。
- 第一节为封面，第二节为正文；节数、方向、页眉、页脚和正文页码必须保留。
- 页眉含 1 个内嵌图与 1 个浮动图；页脚含 `PAGE` 域。生成器只设置打开时更新域，不重建页眉页脚。
- 正文允许模板表格单元格随内容自然跨页，禁止用固定行高截断文字或图表。

## 字体与表格

- 封面标题保持模板 24 pt；封面填写字段使用模板原有 18 pt 加粗与下划线。
- 正文与表格主体沿用宋体/Times New Roman，主体约 10.5–12 pt；密集的课程目标统计表可使用 8 pt，但不得小于 8 pt。
- 新增统计表使用真实 Word 表格和清晰边框；表头浅蓝底、居中、可重复，行不可拆分。
- 图表使用固定蓝/橙配色，数字和图例必须有文字，不能只依赖颜色表达。

## 稳定槽位

| 位置                           | 语义                   | 填充规则                                           |
| ------------------------------ | ---------------------- | -------------------------------------------------- |
| `word/document.xml` 顶层表格 0 | 封面课程名称           | 课程正式名称                                       |
| 封面正文段落 9–12              | 学院、专业、年级、班级 | 仅替换原下划线运行文字，保留段落与下划线           |
| 顶层表格 3                     | 封面教师姓名           | 当前课程教师显示名                                 |
| 顶层表格 4                     | 课程基本信息           | 课程、学期、性质、学分、班级、学生人数、教师       |
| 顶层表格 5 行 1                | 课程目标               | 正式课程目标代码与陈述                             |
| 顶层表格 5 行 3                | 成绩组成与分布         | 确定性公式、分布表、分布图和统计说明               |
| 顶层表格 5 行 5                | 课程目标达成           | 确定性统计表、总体图、AI/教师文字和逐目标图        |
| 顶层表格 6 行 1                | 学生评价               | 只使用问卷聚合与去标识化主题；小样本时显示抑制说明 |

顶层表格 1、2 的“课程名称/教师姓名”标签，第三方评价表、附件清单、校徽、页眉页脚和所有审核签字区属于保留项，不得删除或自动填入审核意见。

## 内容与审核边界

- 数字、成绩公式、成绩分布、课程目标达成度和图表由确定性程序生成。
- AI 只接收去标识化聚合，生成成绩分析、目标分析、学生评价概括、课程总结和持续改进初稿。
- AI 输出先保存为不可变初稿；教师必须逐项查看，可修改后确认。
- AI 审核稿与正式 DOCX 使用不同私有存储键。未确认时正式 DOCX 下载必须返回冲突错误。
- 教师确认保存最终文字、审核人、时间和备注；确认后的正式 DOCX 不原地修改，后续变化通过新报告版本完成。
- 课程评价小组意见、学院意见、签字和日期属于平台外审核，本系统始终留空。

## 包保留与质量门

- 以模板副本为基础原位填充，不从空白文档重建。
- 必须保留 `styles.xml`、`numbering.xml`、主题、页眉、页脚、图片、关系、节属性、页码域和未编辑表格。
- 每次生成后至少重新打开检查：2 个节、8 个顶层表格、页码域、页眉浮动图、审核签字区原文和全部图形。
- 固定样例必须用 Microsoft Word 或 LibreOffice 渲染为逐页图片并检查全部页面；不得只依赖文本提取。
- 视觉门：无裁切、重叠、破表、缺字、异常换页或签字区误填；课程目标较多时允许正文页数增加。

## 数据迁移与回滚

- 人工审核迁移只新增枚举、审核字段、正式 DOCX 元数据和外键，不删除或改写历史报告、成绩或问卷。
- 迁移前的报告保留为旧版 AI 审核稿；因旧文字快照缺少逐目标与总结分段，需按 v2 规则重新生成后再审核，不静默补写结论。
- 回滚应用代码时可继续读取历史审核稿；数据库列已有数据后不得以破坏性脚本删除，需先导出审核文字和正式 DOCX 元数据。
