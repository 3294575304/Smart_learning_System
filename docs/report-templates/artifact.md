# 课程教学质量分析报告模板（2024 版）

## 来源与保真策略

- 基线文件：`课程教学质量分析报告模板(2024版）.docx`
- SHA-256：`659ed18e3577332acd6ade374c7bd477e272218285ee78ae3013013017e96dd8c54`
- 版式：A4 纵向，左右页边距约 21.3/22.1 mm，上下约 10.2 mm；两节、八个顶层表格。
- 字体：标题 24 pt；正文与表格主体主要为宋体/Times New Roman 10.5–12 pt。
- 生成器以模板的页结构和字段顺序为规范，不填课程评价小组、学院审核、签字和日期。

## 字段映射

| 模板区域           | 数据来源                                         |
| ------------------ | ------------------------------------------------ |
| 封面课程名称、教师 | 课程、教师档案                                   |
| 课程基本信息       | 课程、班级、报告生成参数                         |
| 课程目标           | 正式考核方案课程目标                             |
| 成绩构成           | 正式考核方案或上传工作簿列映射                   |
| 成绩分布           | 报告统计快照，特殊状态不计入分布分母             |
| 课程目标达成度     | 正式达成度运行；上传源无此证据时明确标注“未提供” |
| 学生评价           | 问卷未上线或无数据时明确标注“暂无平台问卷数据”   |
| 总结与改进         | 确定性统计文字；AI 失败时仍生成基础报告          |

## 工作簿

输出包含“总评”和各考核分项明细。学号固定为文本；总评使用标准 Excel 公式；缺失成绩为空并另列状态，禁止使用 `211` 等魔法值。上传工作簿只生成报告快照，不回写正式成绩台账。

## 运行依赖

DOCX 生成器通过受控子进程调用 Python，生产环境应安装 `services/quality-reports/requirements.txt`，并用 `QUALITY_REPORT_PYTHON` 指向该解释器。依赖不可用时后台任务记录安全失败码，不影响成绩台账和既有文件下载。
