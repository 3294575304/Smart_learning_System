## 验收结论

1. 非当前课程、超进度、未审核/停用、缺少解析、近期重复和难度不匹配题目均在服务端排除。
2. 推荐周期冻结图谱、画像、掌握度、教学进度、规则和题目—Concept 来源，理由及版本可追溯。
3. 客观练习和 Python 判题完成后更新课程事件、追加式 Concept 证据、掌握度与画像；同分重判也以评测修订键形成新修订，系统故障不记零分。
4. Python 推荐复用迭代五执行器和隐藏用例隔离，不伪造作业、提交或课程成绩。
5. 自述单独保存，学生可修改、确认和软删除；发送 AI 前去标识化，输出仅允许课程内 Concept ID，失败走规则降级。
6. 旧 MVP 推荐、旧作业与历史证据不回填、不改写。
