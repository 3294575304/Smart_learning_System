# 课程测试数据

## 匿名结课问卷测试数据

```powershell
node --conditions=react-server --import tsx scripts/seed-course-survey-test-data.ts --course-id <课程ID> --classroom-id <班级ID>
# 默认只预览，追加 --apply 执行。
```

复用正式大纲派生题目，为每名在读学生建立参与去重记录，另独立生成等量匿名模拟回答。问卷与开放意见均标记为测试数据，包含课程目标自评、五项教学评价和两道开放题。匿名回答不保存学生 ID，不从学生身份或成绩推导回答；随机记录 ID、统一时间戳、独立批量写入避免建立身份—回答关联。

问卷和全班回答在一个事务内写入，直接保存为已结束的测试问卷，不发送填写通知，不计入成绩，不改写其他问卷。随后调用现有汇总服务生成可用于报告功能测试的聚合快照；若汇总失败，重跑可恢复且不会重复生成回答。现有正式问卷、名单变化或大纲变化会阻止自动写入。批次审计记录只包含数量、来源版本及名单指纹，不保存身份与回答的映射。

教师从课程的“结课问卷”入口查看统计；新生成的平台报告可能纳入最近一次已关闭的测试问卷，已有报告快照不变。清理时先核对报告等引用关系，不能直接删除已有正式历史。

## 考勤与成绩测试数据

仅用于本地开发或演示班级。脚本复用现有五类正式考核方案、考勤规则和总评计算；不改变 Schema，不需要 migration，不创建账号。

```powershell
npx tsx scripts/seed-course-test-data.ts --course-id <课程ID> --classroom-id <班级ID> --start-date 2026-03-02
# 检查预览后，使用相同参数追加 --apply 写入。
```

每名在读且有效的学生生成 24 条考勤、8 次实验成绩、8 次作业成绩、期中和期末各 1 次成绩，以及 1 条考勤汇总成绩。课次按每周两次、间隔三天排定；所有课次必须已结束。日期是模拟安排，不代表真实教学记录。

成绩采用百分制，同类实验和作业等权平均，课程总评按正式方案权重计算。考勤汇总复用正常 1、迟到/早退 0.8、缺勤 0、请假排除的现有规则。分数为可复现的模拟值，与学生身份属性无关。

生成结果显示在教师课程的考勤和成绩台账中，名称以 `【测试数据】` 开头，写入修订和批次审计。作业、实验和考试是逐次成绩记录，不创建题目、作答或知识点掌握证据。成绩保留未发布状态；需要测试学生成绩查询或平台正式成绩报告时，由教师在台账中审核并发布。

脚本拒绝生产环境、已归档课程/班级及已有非本批次成绩或考勤的班级。首次执行在一个 Serializable 事务内创建所有数据并计算总评，失败整体回滚。同一班级同一名单、方案和日期重复执行返回已有批次，不覆盖后续人工修订。改动名单、方案或日期后重跑会拒绝覆盖。

批次摘要（仅 ID、数量和参数，无姓名、学号或密码）存于私有且 Git 忽略的 `.data/course-test-data/<台账ID>.json`，同时保存于数据库审计。生成后不自动删除：需要退出演示时可取消测试考勤、停用测试成绩项并重新计算，保留审计历史；整批清理须根据批次 ID 单独核对引用关系，不能删除正式发布、报告或学生历史数据。
